## 🚀 Local Development

To run or preview locally, you can open `index.html` directly in any web browser, or run a quick local server:

```bash
# Using Python
python -m http.server 8000

# Or using npx
npx serve .
```

Then visit [http://localhost:8000](http://localhost:8000).

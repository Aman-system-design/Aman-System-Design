# Agent Guidance for Aman's PM Portfolio

Welcome, AI agent! This repository contains the source code for Aman's personal Product Management portfolio website, inspired by the playful, tactile, and metric-focused aesthetic of itspsneha.com.

## Architecture
- `index.html`: Clean, semantic HTML5 structure with schema metadata.
- `style.css`: Minimalist tactile styling with Manrope typography, Lego brick color keys, and responsive design.
- `portfolio-data.js`: Central source of truth for all PM copy, metrics, projects, field notes, and links.
- `app.js`: Dynamic DOM hydration, Three.js 3D brick playground with tactile Web Audio snap sound synthesis, interactive filter key, and live customizer.
- `.github/workflows/static.yml`: Automated GitHub Pages deployment pipeline.
